Provider credentials

        
On the host, sign in to Codex:

        cloud-agents login-codex
        

          Or import an API key / Claude subscription token using the host CLI.
          Credentials never pass through this client.
        

        cloud-agents credential claude-token
        

          Paste the token, then press Ctrl-D. Use
          claude setup-token to obtain it. See the repository
          README for Git access and remote setup.
